# Ulus System Design Standards

Ulus depends on good system design.
Our job as Ulus Tech is to make Ulus systems the best.
We have created this public resource, so you can design like Ulus.

There is no real competition if you work not for yourself, but for the people.
This design system is for you, and when you create something using this system, that will be for us.
So yeah, we give away how Ulus designs systems.
Because what makes us is not a couple lines of text, but the ideal, and our vision.

*Get your shit together, we have systems to fix.*
